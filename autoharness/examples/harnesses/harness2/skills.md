## Bugfix Playbook
1. Read the failing module and its tests.
2. Reproduce the failure or trace the exact root cause.
3. Apply a minimal fix preserving existing signatures.
4. Re-run tests to confirm zero regressions.

## Direct Q&A Playbook
1. Read the referenced file(s) without modifying workspace state.
2. Return the exact answer concisely in the format requested.
